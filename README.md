# 🌿 AgroLink – Agricultural Marketplace Platform

AgroLink is a full-stack web application that connects **farmers, bulk buyers, and logistics providers** in a single platform. It enables transparent pricing, efficient trade, and optimized logistics in the agricultural supply chain.

---

## 🚀 Project Overview

AgroLink solves inefficiencies in the agricultural market by allowing:
- Buyers to post product prices and demands  
- Sellers (farmers) to choose the best offers  
- Logistics providers to offer transport services  
- Sellers to select the most cost-effective delivery option  

---

## 👥 User Roles

**Buyers**
- Post product demands with pricing
- Manage and track requests

**Sellers**
- View and compare buyer offers
- Select buyers and logistics providers
- Create and manage orders

**Logistics Providers**
- Add transport services with pricing
- Get selected for deliveries
- Manage service listings

---

## ✨ Key Features

- Role-based authentication system  
- Real-time price comparison  
- Logistics cost optimization  
- Order management workflow  
- Responsive dashboard UI  

---

## 🧠 Core Concept

AgroLink follows a reverse marketplace model:

**Buyers set prices → Sellers choose best offers → Logistics completes delivery**

---

## 🏗️ Tech Stack

- **Frontend:** React.js  
- **Backend:** Spring Boot (REST APIs, JWT)  
- **Database:** MongoDB  

---

## 🔄 Workflow

Buyer posts demand → Seller selects best buyer → Seller chooses logistics → Order created
